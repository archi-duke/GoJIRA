# VOS (Voice of Stakeholders)

## Cloud AI 관제 및 분석

1. 상위 시스템으로부터 부여받은 작업을 분석할 수 있어야 합니다.
2. 하위 On-Device 또는 Edge 기반 설비의 상태를 종합적으로 모니터링할 수 있어야 합니다.
3. 하위 로봇의 상태를 종합적으로 모니터링할 수 있어야 합니다.
4. 설비 및 로봇의 상태를 참고하여 관제 업무를 수행할 수 있어야 합니다.

## Edge/On-Device AI 기반 자율 제어

5. 각 설비에 Edge/On-Device AI를 탑재하여 할당된 작업을 자율적으로 판단할 수 있어야 합니다.
6. 각 로봇에 Edge/On-Device AI를 탑재하여 할당된 작업을 자율적으로 판단할 수 있어야 합니다.
7. 기기 간(P2P) 협업을 수행할 수 있어야 합니다.

## 무중단 운영

8. 클라우드 연결이 단절되는 상황에서 자율 안전 모드로 전환할 수 있어야 합니다.
9. 클라우드 연결 단절 시에도 무중단 운영을 보장할 수 있어야 합니다.

## 대규모 트래픽 처리 안정성

10. 설비와 로봇의 수가 지속적으로 증가하더라도 안정적으로 관제를 수행할 수 있어야 합니다.
11. 과도한 네트워크 트래픽이 발생하더라도 지연 없이 오케스트레이션을 수행할 수 있어야 합니다.
12. 대규모 데이터 처리 시에도 고가용성 환경을 지원할 수 있어야 합니다.
